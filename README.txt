TradeJournal Website V1
========================

Static website ready for GitHub Pages.

Files:
- index.html
- styles.css
- assets/ (screenshots from the supplied TradeJournal V1 capture set)

To customize before publishing:
1. Replace the Windows Download placeholder in index.html with your real release/download URL.
2. Replace the Discord placeholder with your real Discord invite URL.
3. Add tutorial video URLs or embeds in the Video Tutorials section.
4. Review wording and screenshots before public launch.

No external libraries or build step are required.
